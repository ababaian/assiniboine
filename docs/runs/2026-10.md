# The October 2026 run

Run 2026-10-02 to 2026-10-05 with an earlier version of this pipeline,
superseded by the [November 2026 run](2026-11.md). Its code is tagged
`run-2026-10` in git (commit `29946fe`):

```bash
git show run-2026-10 --stat
git worktree add ../assiniboine-2026-10 run-2026-10
```

It predates the overlap trim, the 200 nt floor and the removal of a
deduplication stage, so its outputs carry the defects listed below. Its
data is at `s3://petadex/circs-results/run-2026-10/`.

## Defects carried into its outputs

* **Lengths are 30 nt too long** and every fold contained a spurious
  tandem repeat, because the terminal overlap was not trimmed. Any
  length-based cut applied to those tables is shifted by 30.
* **Hairpin-class records were folded as circles** without being
  labelled, so they cannot be separated in the tables.
* **The shortlist's tier 2 is truncated** to 2,000 rows out of a
  qualifying pool of 13,399, so the effective confidence cut is 0.998
  rather than the stated 0.8, and 11,399 candidates meeting the stated
  criteria are absent.
* **The completion gate counted every `.done` marker** rather than those
  of the current chunk set, so an earlier run's markers could declare a
  new run complete. Fixed in the November pipeline.
* **`below_confidence_floor` is always False**; threshold on `confidence`.
* **The deduplication map was deleted**, so a hit can no longer be
  expanded back to every SRA run carrying that circle. The November run
  does not deduplicate.

## Decisions

**2026-10-30, no archive folders.** A copy of this pipeline was briefly
kept in an `archive/` directory so past versions would not have to be dug
out of history. That is what git does, so the directory was removed and
the commit tagged instead. Version history goes in git, run records go in
`docs/runs/`.
